`<ds-calendar>` er en standalone shadow-dom popup-kalender.
Den eier kalender-UI og sender valgt dato via event, men eier ikke input-feltet.

## Når Bruker Du Hva?

- Bruk [Calendar (Shadow DOM)](../calendar/) når du vil ha popup-kalender som egen komponent.
- Bruk [Date Field (Light DOM)](../date-field/) når du vil ha input + calendar ferdig koblet.
- Bruk [Input](../input/) når du kun trenger native date/time/datetime-local-atferd uten custom popup.

## Import

```ts
import { defineDsCalendar } from "@fristil/designsystem/calendar"

defineDsCalendar()
```

## Hvordan den brukes

1. `ds-calendar` viser trigger-knapp og popup-kalender.
2. Når bruker velger en dag, sender komponenten event `date-select`.
3. Appen bestemmer hva som skal oppdateres (input, state, API-kall, osv.).

## ds-calendar API

| Attributt | Type | Effekt |
|---|---|---|
| `value` | string | Valgt dato i `YYYY-MM-DD` |
| `open` | boolean | Åpner/lukker popup |
| `disabled` | boolean | Deaktiverer trigger |

## Events

| Event | Detail | Når |
|---|---|---|
| `date-select` | `{ value: string }` | Når en dag velges i popup |
| `input` | `Event` | Samtidig med dato-valg |
| `change` | `Event` | Samtidig med dato-valg |
