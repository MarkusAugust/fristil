Stien fra forsiden til der brukeren står nå. Klassen settes på en `<ol>` inne i en `<nav>`: rekkefølgen betyr noe, så listen må være nummerert selv om tallene ikke vises.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<nav aria-label="Du er her">
  <ol {...lt.breadcrumbs()}>
    <li><a href="/">Forsiden</a></li>
    <li aria-current="page">Bostøtte</li>
  </ol>
</nav>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const sti = document.querySelector<HTMLOListElement>("#brodsmuler")

lt.setAttributes(sti, lt.breadcrumbs())
```

Tre ting må stå i markupen:

| Hva | Hvorfor |
| --- | --- |
| `<nav aria-label="Du er her">` | Skjermlesere lister opp navigasjonene på siden. Uten teksten heter denne bare «navigasjon». |
| `<ol>`, ikke `<ul>` | Rekkefølgen er en del av betydningen |
| `aria-current="page"` på siste steg | Sier hvilken side brukeren er på. Fargen alene sier ingenting. |

Skilletegnet legges inn med CSS. Sto skråstreken i markupen, ville skjermlesere lest «skråstrek» mellom hvert steg.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-breadcrumbs` | Listen med stegene |

| Variabel | Standard |
| --- | --- |
| `--lt-breadcrumbs-gap` | `var(--lt-spacing-2)` |

Skilletegnet kommer fra `::before` på hvert steg etter det første, og kan byttes. Ta med den tomme alternativteksten etter tegnet: generert innhold leses opp, og uten den sier skjermleseren det nye tegnet mellom hvert steg, slik den sa «skråstrek» før. Den første regelen er reserven for nettlesere som ikke kjenner formen og ellers forkaster hele deklarasjonen, som i stilarket selv:

```css
.lt-breadcrumbs li + li::before {
	content: "›";
}

@supports (content: "/" / "") {
	.lt-breadcrumbs li + li::before {
		content: "›" / "";
	}
}
```

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Accessibility

- Siste steg skal være der brukeren er nå, ikke et sted å gå. Enten som en lenke med `aria-current="page"`, eller som ren tekst.
- Ikke kort ned stegene til «...» på liten skjerm uten at de kan foldes ut. Da mister brukeren nettopp den oversikten stien er til for.
- Stien erstatter ikke en tilbakeknapp. Den viser hvor i strukturen brukeren er, ikke hvor hen kom fra.
