Navigering mellom sider i en lang liste. Hver side er en lenke med sin egen adresse, ikke en knapp: da kan brukeren åpne side tre i ny fane, kopiere adressen, og komme tilbake med tilbakeknappen.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<nav aria-label="Sidenavigering">
  <ul {...lt.pagination()}>
    <li><a href="?side=1" aria-current="page">1</a></li>
    <li><a href="?side=2">2</a></li>
  </ul>
</nav>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const liste = document.querySelector<HTMLUListElement>("#sider")

lt.setAttributes(liste, lt.pagination())
```

`lt.pagination.gap` gir klassen på hoppet i nummerrekken. Se [Typesikker bruk](../../type-safe-use/).

Et tall alene sier lite når det leses opp midt i en rekke. `aria-label="Side 3"` gjør lenken forståelig, og `aria-current="page"` sier hvilken brukeren står på.

Er brukeren på første side, skal «Forrige» ikke være en lenke. Bytt den ut med `<span aria-disabled="true">` eller la den være ute.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-pagination` | Listen med sidene. Lenkene og knappene inni styles av komponenten. |
| `.lt-pagination__gap` | Hoppet i nummerrekken, som «1 2 … 9 10» |

| Variabel | Standard |
| --- | --- |
| `--lt-pagination-gap` | `var(--lt-spacing-1)` |
| `--lt-pagination-size` | `var(--lt-spacing-10)` |
| `--lt-pagination-radius` | `var(--lt-spacing-1)` |

`--lt-pagination-size` er minste bredde og høyde på hvert nummer. WCAG 2.2 krever 24 piksler; standarden her er 40, fordi et nummer i en lang rekke er lett å bomme på med finger.

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Accessibility

- Si hvor brukeren er, også utenfor selve velgeren: «Viser 21 til 40 av 184 saker» over listen hjelper mer enn tallrekken alene.
- Etter at en ny side er lastet, flytt fokus til toppen av listen. Ellers står fokus igjen på et tall som nå betyr noe annet.
- Har listen få sider, vis alle. Hoppet med «…» er bare verdt det fra rundt ti sider og oppover.
- Er innholdet en strøm uten slutt, er «Vis flere»-knapp ofte bedre enn sidetall. Uendelig rulling uten knapp gjør bunnteksten uoppnåelig.
