Ren CSS på et vanlig `<input type="checkbox">`, så tastatur, `FormData` og nettleserens egen validering virker som før. Skal brukeren velge ett av flere alternativer, er [Radio](../radio/) riktig. Er valget av eller på for en innstilling som slår inn med en gang, bruk [Switch](../switch/).

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<div className={lt.checkbox.row}>
  <input {...lt.checkbox()} id="vilkar" />
  <label {...lt.label()} htmlFor="vilkar">Jeg godtar vilkårene</label>
</div>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt, type FieldState } from "@lo-tek/interfaces"

const boks = document.querySelector<HTMLInputElement>("#bekreft")
if (!boks) throw new Error("fant ikke elementet")

boks.addEventListener("change", () => {
  const tilstand: FieldState = boks.checked ? "default" : "invalid"

  lt.setAttributes(boks, lt.checkbox({ state: tilstand }))
})
```

`lt.checkbox()` setter `type` for deg, så boksen ikke kan bli et tekstfelt med boksens stil. `lt.checkbox.row` gir klassen på raden rundt. Se [Typesikker bruk](../../type-safe-use/).

| `data-state` | Brukes til |
| --- | --- |
| *(utelatt)* | Normaltilstand |
| `invalid` | Valideringen har feilet |
| `success` | Valget er bekreftet gyldig. Bruk sparsomt. |

`data-state` er farge. Skjermlesere trenger `aria-invalid="true"` i tillegg. `lt.checkbox({ state: "invalid" })` og [Field](../field/) setter begge.

## Delvis avkrysset

«Velg alle» er verken på eller av når noen av valgene under er krysset av. Den tilstanden finnes bare som en egenskap i JavaScript, ikke som et HTML-attributt:

```html
<div class="lt-checkbox-row">
  <input class="lt-checkbox" type="checkbox" id="alle" />
  <label class="lt-label" for="alle">Velg alle vedlegg</label>
</div>
<div class="lt-checkbox-row">
  <input class="lt-checkbox vedlegg" type="checkbox" id="vedlegg-attest" name="vedlegg" value="attest" checked />
  <label class="lt-label" for="vedlegg-attest">Fødselsattest</label>
</div>
<div class="lt-checkbox-row">
  <input class="lt-checkbox vedlegg" type="checkbox" id="vedlegg-kontrakt" name="vedlegg" value="kontrakt" />
  <label class="lt-label" for="vedlegg-kontrakt">Leiekontrakt</label>
</div>

<script type="module">
  const alle = document.getElementById("alle")
  const valg = document.querySelectorAll(".vedlegg")

  function oppdater() {
    const antall = [...valg].filter((boks) => boks.checked).length

    alle.checked = antall === valg.length
    alle.indeterminate = antall > 0 && antall < valg.length
  }

  // «Velg alle» krysser av eller fjerner alle under.
  alle.addEventListener("change", () => {
    for (const boks of valg) boks.checked = alle.checked
    oppdater()
  })
  for (const boks of valg) boks.addEventListener("change", oppdater)
  oppdater()
</script>
```

Skjermlesere melder tilstanden som «delvis avkrysset» av seg selv. Du trenger ikke `aria-checked="mixed"` på et ekte `<input>`.

## Flere valg som hører sammen

Hører boksene til samme spørsmål, samle dem i en [Fieldset](../fieldset/). Da leses spørsmålet opp før hvert valg.

    <label class="lt-label" for="varsel-epost">E-post</label>
  </div>

  <div class="lt-checkbox-row">
    <input class="lt-checkbox" type="checkbox" id="varsel-sms" name="varsel" value="sms" />
    <label class="lt-label" for="varsel-sms">SMS</label>
  </div>
</fieldset>
`} />

Like `name`-verdier gir én nøkkel med flere verdier i `FormData`. Les dem med `formData.getAll("varsel")`.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-checkbox` | Selve boksen |
| `.lt-checkbox-row` | Raden som holder boksen og teksten ved siden av hverandre |

| Variabel | Standard |
| --- | --- |
| `--lt-checkbox-size` | `var(--lt-spacing-5)` |
| `--lt-checkbox-radius` | `var(--lt-spacing-1)` |

Haken og streken tegnes fra `--lt-icon-check` og `--lt-icon-dash`, som snur med temaet. Se [Tilpasning](../../customising/).

## Tilgjengelighet

- Hver boks trenger en `<label>` med `for`. Uten den er klikkflaten bare selve boksen, og skjermleseren leser ingenting.
- Teksten skal si hva som skjer når boksen er krysset av, ikke hva spørsmålet het. «Send meg nyhetsbrev», ikke «Nyhetsbrev».
- Ikke send skjemaet eller naviger når en boks endres. Brukeren forventer å kunne krysse av flere før noe skjer.
- Er avkryssing påkrevd, sett `required` på boksen. Da stopper nettleseren innsendingen selv.
