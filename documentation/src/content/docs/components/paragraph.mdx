Body text with a readable line length. The width is limited to 70 characters, because longer lines make it hard to find the start of the next one. That is the most common reason a text is hard to read even when the font is large enough.

## How to use it

`lt` is used in two ways, and which one depends on whether you create the element or find it.

**If you create the markup,** spread the attributes in. That is the way in React, Astro and anything else that renders:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<p {...lt.paragraph({ variant: "lead" })}>
  Housing benefit is means-tested support for people with low incomes.
</p>
```

The import is from `/react` here, since the block is JSX. From there the keys are `className` and `htmlFor`. In Astro and anything else without React, import `@lo-tek/interfaces` and you get `class` and `for`.

**If the element is already there,** set them on it. That is the way when you enhance HTML a server or a template has sent:

```ts
import { lt } from "@lo-tek/interfaces"

const lead = document.querySelector<HTMLParagraphElement>("#lead")

lt.setAttributes(lead, lt.paragraph({ variant: "lead" }))
```

</Fragment>
</Example>

| Attribute | Used for |
| --- | --- |
| *(omitted)* | Body text |
| `data-variant="lead"` | The lead paragraph right below the heading |
| `data-size="large"` | Text that should stand out |
| `data-size="small"` | Asides, dates, source references |

Consecutive paragraphs get space between them on their own.

## Classes you can style

| Class | What it is |
| --- | --- |
| `.lt-paragraph` | The paragraph. The size comes from `data-size`, the lead from `data-variant`. |

| Variable | Default |
| --- | --- |
| `--lt-paragraph-width` | `70ch` |
| `--lt-paragraph-gap` | `var(--lt-spacing-3)` |
| `--lt-paragraph-line-height` | `var(--lt-line-height-article)` |

`--lt-paragraph-line-height` applies to the default size. `data-size="large"` and `data-variant="lead"` set their own line height.

If the paragraph sits in a column that is already narrow enough, the limit can be removed:

```css
.lt-card .lt-paragraph {
	--lt-paragraph-width: none;
}
```

See [Customising](../../customising/) for how the variables and the layer work.

## Accessibility

- Do not use `<br>` to make paragraphs. A new `<p>` is what screen readers can jump between.
- `data-size="small"` should not be used for anything the user has to read. Terms in small print are as hard on screen as on paper.
- Leave the line length alone. It is the simplest difference between a text that is read and one that is skimmed.
