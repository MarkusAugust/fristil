Komponentene er delt i tre, og skillet går på hvem som lager markupen og om en web-komponent legger oppførsel på den. Det avgjør hva du skriver selv og hva systemet gjør for deg. Begrunnelsen står i [Markup og oppførsel](../markup-og-oppforsel/).

Hver side viser komponenten i ren HTML og med byggefunksjonen i TypeScript, med kode du kan lime rett inn. Web-komponentene har i tillegg egne faner for React og Datastar, og de fleste for Astro.
