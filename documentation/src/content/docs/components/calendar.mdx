En knapp som åpner et kalenderpanel. Den eier kalenderen og datovalget, men ikke noe inndatafelt. Når brukeren velger en dag, sender den en hendelse, og appen bestemmer resten. Bruker Shadow DOM, så stilene inni er skjermet.

**Velg Calendar** når datoen skal påvirke noe annet enn et tekstfelt: filtrere en liste, hoppe til en uke, sette et intervall. Skal den ned i et felt, er [Date Field](../date-field/) den koblingen ferdig løst.

## Kom i gang

```ts
// main.ts, kjøres én gang når appen starter
import { defineFsCalendar } from "@fristil/designsystem/calendar"

defineFsCalendar()
```

Kalenderen tar med seg stilene sine i Shadow DOM, så den trenger ingen CSS-import utover `tokens.css`.

<Tabs>

    ```html
    <fs-calendar id="fakturadato" value="2026-05-31"></fs-calendar>

    <script type="module">
      import { defineFsCalendar } from "@fristil/designsystem/calendar"
      defineFsCalendar()

      document.getElementById("fakturadato")

          document.getElementById("resultat").textContent = hendelse.detail.value
        })
    </script>
    ```
  </TabItem>
</Tabs>

Komponenten lagrer datoen, men gjør ingenting med den. Det er med vilje, for den vet ikke hva dato betyr i appen din.

## Attributter

| Attributt | Type | Effekt |
| --- | --- | --- |
| `value` | streng | Valgt dato som `ÅÅÅÅ-MM-DD`. Speiles tilbake når brukeren velger. |
| `open` | boolsk | Om panelet er åpent |
| `disabled` | boolsk | Deaktiverer knappen |
| `trigger-hidden` | boolsk | Skjuler knappen, så panelet styres fra koden |

## Hendelser

| Hendelse | `detail` | Når |
| --- | --- | --- |
| `date-select` | `{ value: string }` | En dag velges. `value` er alltid `ÅÅÅÅ-MM-DD`. |
| `input` | ingen | Samtidig med `date-select` |
| `change` | ingen | Samtidig med `date-select` |

Alle tre bobler og krysser skyggegrensen, så du kan lytte lenger opp i treet.

I TypeScript må typen oppgis for å komme til `detail`:

```ts
kalender.addEventListener("date-select", (hendelse) => {
	const valg = hendelse as CustomEvent<{ value: string }>
	console.log(valg.detail.value)
})
```

I en `<script type="module">` i en HTML-fil skriver du bare `hendelse.detail.value`. `as` er TypeScript og gir `SyntaxError` i nettleseren.

## Deler du kan style

Komponenten bruker Shadow DOM, så vanlige selektorer når ikke inn i den. Disse delene er pekt ut med `part` og kan styles utenfra med `::part()`:

| Del | Hva det er |
| --- | --- |
| `trigger` | Knappen som åpner kalenderen |
| `popup` | Panelet |
| `popup-header` | Raden med måned og piler |
| `month-label` | Månedsnavnet |
| `month-controls` | Beholderen rundt pilene |
| `month-button` | Hver av de to pilene |
| `weekday-row` | Raden med ukedagsnavn |
| `weekday` | Ett ukedagsnavn |
| `day-grid` | Rutenettet med dager |
| `day` | Hver dagknapp |
| `day-today` | Dagknappen for i dag |
| `day-selected` | Den valgte dagknappen |
| `day-outside` | Dager fra måneden før og etter |

```css
fs-calendar::part(trigger) {
	border-radius: 9999px;
}

fs-calendar::part(day-selected) {
	background: #7c3aed;
}
```

Tilstandene er egne delnavn fordi `::part()` er strengere enn vanlige selektorer. To ting virker ikke:

```css
/* Attributtselektor etter ::part() treffer ikke */
fs-calendar::part(day)[data-selected="true"] { }

/* En del har ingen etterkommere utenfra */
fs-calendar::part(popup) .day { }
```

Pseudoklasser virker som normalt, så `::part(day):hover` er greit. Størrelse og form kan også settes med [komponentvariabler](../../tilpasning/#form-og-størrelse).

## Tastatur og tilgjengelighet

| Tast | Virkning |
| --- | --- |
| Piltaster i panelet | Flytter mellom dagene |
| `Escape` | Lukker panelet og gir fokus tilbake til knappen |

Lukkes panelet fordi brukeren klikket eller tabbet et annet sted, blir fokus stående der.

- Panelet skal aldri være eneste vei til datoen. La brukeren skrive den også. Det er derfor [Date Field](../date-field/) alltid har et tekstfelt ved siden av.
- Knappen har en fast `aria-label` inne i Shadow DOM som ikke kan overstyres. Har du flere kalendere på samme side, gi hver av dem en synlig ledetekst i nærheten.
- Dagene fra nabomåneden er dempet, men klikkbare, og bruker derfor `neutral`-tokenene framfor `disabled`.
