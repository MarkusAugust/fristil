`fs-link` er en **pure-css**-komponent for navigasjonstekst med tydelig hover/fokus.
Standardfargen er `--semantic-interactive-main`.

## Import

```html
<link rel="stylesheet" href="@fristil/designsystem/tokens.css" />
<link rel="stylesheet" href="@fristil/designsystem/link.css" />
```

Via bundler:

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/link.css"
```

## Deaktivert lenke

Bruk `aria-disabled="true"` for lenker som ikke skal være klikkbare ennå.

```html
<a class="fs-link" aria-disabled="true" href="/kommer-snart">Kommer snart</a>
```

Dette slår av klikk (`pointer-events: none`) og viser deaktivert visuell tilstand.

---

## Tilgjengelighet

- Bruk `<a>` for navigasjon mellom sider eller ressurser
- Hold lenketeksten konkret: *"Se faktura"* er bedre enn *"Klikk her"*
- Bruk `:focus-visible`-stilen som følger med `fs-link`; ikke fjern outline
- Hvis lenken er deaktivert, bruk `aria-disabled="true"` og vurder å gi forklaring i UI
