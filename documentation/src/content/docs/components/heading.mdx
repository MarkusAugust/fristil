Størrelsen og nivået er to forskjellige ting. Nivået er `<h1>` til `<h6>` og bestemmer strukturen skjermlesere navigerer etter. `data-size` bestemmer bare hvor stor teksten ser ut.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<h1 {...lt.heading({ size: "mega" })}>Søknad om bostøtte</h1>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const tittel = document.querySelector<HTMLHeadingElement>("#seksjon")

lt.setAttributes(tittel, lt.heading({ size: "m" }))
```

Kommer størrelsen fra innhold utenfra, valider den med `lt.heading.isSize(x)`. Se [Typesikker bruk](../../type-safe-use/).

| `data-size` | Font |
| --- | --- |
| `mega` | `--lt-font-size-mega` |
| `xl` | `--lt-font-size-xxl` |
| *(utelatt)* | `--lt-font-size-xl` |
| `m` | `--lt-font-size-l` |
| `s` | `--lt-font-size-m` |
| `xs` | `--lt-font-size-s`, i versaler |

## Nivå følger strukturen, ikke utseendet

En `<h2>` som skal se liten ut er riktig. En `<h4>` valgt fordi den var liten nok, hopper over et nivå, og da blir innholdsfortegnelsen skjermleseren bygger feil:

```html
<h2 class="lt-heading" data-size="s">Vedlegg</h2>
```

Siden skal ha én `<h1>`, og nivåene under skal følge hverandre uten hopp.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-heading` | Overskriften. Størrelsen kommer fra `data-size`. |

Størrelsene er `--lt-font-size`-tokenene direkte, så en endring i skalaen slår gjennom overalt på én gang. Vekten og linjeavstanden er egne variabler, fordi en organisasjon som tar systemet i bruk gjerne har sin egen typografi:

| Variabel | Standard |
| --- | --- |
| `--lt-heading-font-weight` | `var(--lt-font-weight-bold)` |
| `--lt-heading-line-height` | `var(--lt-line-height-heading)` |

Overskriftene bruker `text-wrap: balance`, så en overskrift over to linjer ikke ender med ett ord alene på den siste.

Se [Tilpasning](../../customising/) for hvordan laget virker.

## Accessibility

- Skjermlesere kan liste opp alle overskrifter og hoppe mellom dem. Det er den vanligste måten å finne fram på en lang side.
- Ikke bruk en overskrift for å gjøre tekst stor. Bruk [Paragraph](../paragraph/) med `data-size="large"`.
- En overskrift uten innhold under seg er ikke en overskrift.
