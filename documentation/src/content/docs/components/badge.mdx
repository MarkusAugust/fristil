`fs-badge` er en **pure-css**-komponent for kompakte statusindikatorer. Fargen styres med `data-color`.

## Import

```html
<link rel="stylesheet" href="@fristil/designsystem/tokens.css" />
<link rel="stylesheet" href="@fristil/designsystem/badge.css" />
```

Via bundler:

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/badge.css"
```

| `data-color` | Token-par | Bruk |
|---|---|---|
| *(ingen)* | `interactive-background` / `interactive-main` | Generell info |
| `success` | `success-background` / `success-foreground` | Aktiv, godkjent, fullført |
| `warning` | `warning-background` / `warning-foreground` | Advarsel, krever oppmerksomhet |
| `danger` | `danger-background` / `danger-foreground` | Feil, avvist, kritisk |
| `neutral` | `disabled-background` / `disabled-foreground` | Inaktiv, arkivert, ukjent |

---

## Tilgjengelighet

- Bruk `<span>` for inline-badges i tekst, `<div>` for standalone-bruk
- Ikke bruk badge som eneste kommunikasjonskanal — understøtt alltid med tekst
- Hvis badget endrer seg dynamisk, legg til `role="status"` og `aria-live="polite"` på et overordnet element
