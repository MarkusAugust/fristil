En boble med et tillegg til noe som allerede står på skjermen. Den må aldri bære informasjon brukeren trenger: på en berøringsskjerm finnes hverken hover eller fokus før noe trykkes.

Er teksten nødvendig for å fylle ut et felt, hører den hjemme i [Help Text](../help-text/) under feltet.

## Slik tar du den i bruk

Boblen er skjult til utløseren får musa eller fokus. Hold musa over knappen under, eller gå til den med Tab, så kommer den fram:

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<span {...lt.tooltip()}>
  <button {...lt.button({ variant: "ghost" })} type="button" aria-describedby="hjelp">?</button>
  <span className={lt.tooltip.bubble} id="hjelp" role="tooltip">Vi sender aldri spam.</span>
</span>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const omslag = document.querySelector<HTMLElement>("#arkiv")

lt.setAttributes(omslag, lt.tooltip())
```

`lt.tooltip.bubble` gir klassen på boblen. Se [Typesikker bruk](../../type-safe-use/).

To ting må stemme:

| Hva | Hvorfor |
| --- | --- |
| `aria-describedby` fra utløseren til boblen | Uten den er boblen bare noe som dukker opp på skjermen, og leses aldri opp |
| `role="tooltip"` på boblen | Sier hva slags tekst det er |

Boblen vises på `:hover` og på `:focus-within`. Fokusdelen er ikke valgfri: en boble som bare kommer med musa finnes ikke for den som bruker tastatur.

## Ikonknapp med navn

En knapp med bare et ikon trenger et navn, ikke en hjelpeboble. De to er forskjellige ting:

```html
<span class="lt-tooltip">
  <button class="lt-button" data-variant="ghost" type="button"
    aria-label="Arkiver saken" aria-describedby="arkiv-hint">
    <svg aria-hidden="true" width="20" height="20">…</svg>
  </button>
  <span class="lt-tooltip__bubble" role="tooltip" id="arkiv-hint">
    Saken kan hentes fram igjen senere
  </span>
</span>
```

`aria-label` er navnet knappen leses opp med. Boblen er tillegget. Bruker du boblen som navn, har knappen ingen navn før den får fokus.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-tooltip` | Omslaget rundt utløseren og boblen |
| `.lt-tooltip__bubble` | Boblen med teksten |

| Variabel | Standard |
| --- | --- |
| `--lt-tooltip-width` | `16rem` |
| `--lt-tooltip-padding` | `var(--lt-spacing-1) var(--lt-spacing-2)` |
| `--lt-tooltip-radius` | `var(--lt-spacing-1)` |

Boblen ligger over utløseren. Står utløseren helt øverst på siden, må du flytte den ned selv:

```css
.lt-tooltip__bubble {
	inset-block-end: auto;
	inset-block-start: calc(100% + var(--lt-spacing-2));
}

/* Broen over gapet må med ned, ellers forsvinner boblen på vei til den. */
.lt-tooltip:is(:hover, :focus-within)::before {
	inset-block-end: auto;
	inset-block-start: 100%;
}
```

Boblen er `display: none` når den er skjult, så den ikke tar plass, og tones inn med `opacity`. En skjult boble er ute av tilgjengelighetstreet, men `aria-describedby` leser teksten den peker på også når den er skjult, så beskrivelsen følger knappen før boblen vises.

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Tilgjengelighet

- Ingenting som bare finnes i boblen kan være nødvendig. Regn med at halvparten av brukerne aldri ser den.
- Hold teksten kort. Boblen kan ikke rulles. Musa kan flyttes fra knappen og opp på boblen uten at den forsvinner, men den lukkes når musa forlater begge.
- Ikke legg lenker eller knapper inni. Boblen er en beskrivelse, ikke et panel.
- **Boblen kan ikke lukkes med Escape.** WCAG 1.4.13 krever at innhold som kommer fram på hover og fokus kan avvises uten å flytte musa eller fokus. Det krever JavaScript, og Tooltip er bare CSS. Bruk den derfor bare der boblen ikke dekker noe brukeren trenger å se, eller bruk [Popover](../popover/), som lukkes med Escape.
- **Boblen flyttes ikke inn fra kanten av skjermen.** Den står midt over knappen. Står knappen helt ved venstre eller høyre kant på en smal skjerm, havner en del av boblen utenfor. Å flytte den krever ankerplassering i CSS, som ikke finnes i alle nettlesere ennå, eller JavaScript. Legg derfor ikke en knapp med boble helt ute ved kanten.
- En boble på et felt som allerede har hjelpetekst er dobbelt opp. Velg én.
