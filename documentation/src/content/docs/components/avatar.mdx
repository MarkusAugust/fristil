En rund flate med et bilde eller initialer. Komponenten sier ingenting om hvem personen er: det gjør teksten ved siden av, eller en tekst du gir bildet.

## Slik tar du den i bruk

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<span {...lt.avatar({ size: "small" })} aria-hidden="true">ON</span>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const bilde = document.querySelector<HTMLElement>("#profil")

lt.setAttributes(bilde, lt.avatar({ size: "large" }))
```

Lista som lar bildene overlappe har ingen attributter, bare en klasse, og den ligger på funksjonen:

```tsx
<ul className={lt.avatar.stack}>
  <li><span {...lt.avatar({ size: "small" })} aria-hidden="true">ON</span></li>
</ul>
```

</Fragment>
</Example>

| Attributt | Effekt |
| --- | --- |
| `data-size="small"` | Til en tabellrad eller en liste |
| *(utelatt)* | Ved siden av et navn |
| `data-size="large"` | På en profilside |
| `data-variant="square"` | Avrundet firkant, for logoer og virksomheter |

## Med navn ved siden av

<Example stiler={["avatar"]} kode={`
<span class="lt-avatar" data-size="small" aria-hidden="true">ON</span>
<span>Ola Nordmann</span>
`} />

Står navnet der allerede, er bildet pynt. `aria-hidden="true"` hindrer at initialene leses opp som «O N» foran navnet.

Bildet og navnet er to elementer ved siden av hverandre. Hvordan de stilles opp er appens oppsett, ikke komponentens: en flex-rad med `gap`, en tabellcelle, eller hva siden ellers bruker.

Står bildet alene, må det si hvem det er:

```html
<span class="lt-avatar">
  <img src="/bilder/ola.jpg" alt="Ola Nordmann" />
</span>
```

## Flere bilder som overlapper

<ul class="lt-avatar-stack">

  <li><span class="lt-avatar" data-size="small" aria-hidden="true">KB</span></li>
  <li><span class="lt-avatar" data-size="small" aria-hidden="true">MH</span></li>
</ul>
<p>Ola Nordmann, Kari Berg og Mats Hansen følger saken</p>
`} />

Rekkefølgen snus i CSS: det første elementet i markupen står lengst til høyre i stabelen. Navnene må stå et sted, som i teksten under: initialer er ingen identifikasjon.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-avatar` | Flaten med bildet eller initialene |

| Klasse | Hva det er |
| --- | --- |
| `.lt-avatar-stack` | Lista med bilder som overlapper |

| Variabel | Standard |
| --- | --- |
| `--lt-avatar-size` | `var(--lt-spacing-10)` |
| `--lt-avatar-radius` | `var(--lt-spacing-1)` |
| `--lt-avatar-stack-overlap` | `calc(var(--lt-spacing-2) * -1)` |

`--lt-avatar-size` gjelder standardstørrelsen. `data-size="small"` og `data-size="large"` setter sin egen.

`--lt-avatar-radius` gjelder bare firkantvarianten. Den runde er alltid rund. Se [Tilpasning](../../customising/).

## Tilgjengelighet

- Initialer er ingen identifikasjon. To personer kan ha de samme, så navnet må stå et sted.
- Et `<img>` uten `alt` leses opp som filnavnet. Er bildet pynt, skriv `alt=""`.
- Ikke la fargen på flaten bety noe. Den er tilfeldig for den som ikke ser den.
