Serveren skriver rollene og skjuler panelene som ikke er valgt. Komponenten tar piltastene.

Det er hele grunnen til at den finnes. I en fanerad skal Tab hoppe forbi hele raden og inn i panelet, mens piltastene flytter mellom fanene. Et sett knapper uten den koblingen gir én tabbestopp per fane, og skjermleseren sier «knapp» der den skulle sagt «fane, 2 av 3, valgt».

:::note[Bruk byggefunksjonen og komponenten sammen]
`fs.tabs()` gir deg rollene, hvilke paneler som er skjult og hvilken fane som er tabbestopp. Elementet gir deg piltastene, Home og End, som en funksjon ikke kan gjøre. Her trenger du **begge**.

Det er bare [`<fs-field>`](../field/) som er enten eller, fordi den ene jobben dens, koblingen, er markup. Se [Markup og oppførsel](/markup-og-oppforsel/#byggefunksjon-eller-web-component).
:::

`hidden` på panelene kommer fra serveren, ikke fra komponenten. Gjorde komponenten det, ville alle panelene vist seg til skriptet hadde kjørt, og innholdet hoppet når de skjulte seg selv.

## Hvilken fane som er valgt

`selected` sier hvilken fane som er valgt når markupen lages, og er indeksen i lista:

```ts
const faner = fs.tabs({ id: "sak", count: 3, selected: 1, label: "Deler av saken" })
```

Serveren bestemmer altså utgangspunktet. Etterpå er det `aria-selected` i markupen som gjelder, og komponenten leser derfra.

Komponenten har ikke noe `selected`-attributt. Svaret står i markupen, som `aria-selected` på fanen, og leses derfra. To steder å holde i synk er ett for mye.

```ts
const faner = document.querySelector("fs-tabs")
if (!faner) throw new Error("fant ikke elementet")

faner.selected // 0
faner.select(1) // velger «Vedlegg» og sender `tab-select`
```

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.fs-tabs__list` | Raden med knapper. Serveren gir den `role="tablist"` |
| `.fs-tabs__panel` | Ett panel. Den valgte er uten `hidden` |

Knappene har ingen egen klasse, de styles som `.fs-tabs__list button`.

| Variabel | Reserve |
| --- | --- |
| `--fs-tabs-gap` | `var(--size-1)` |
| `--fs-tabs-padding` | `var(--size-2) var(--size-4)` |
| `--fs-tabs-panel-space` | `var(--size-4)` |

```css
.fs-tabs__list {
  --fs-tabs-gap: 0;
}
```
## Tilgjengelighet

Fanene er `role="tab"` i en `role="tablist"`, og panelene er `role="tabpanel"` pekt til med `aria-labelledby`. Alt dette står i markupen fra serveren, så semantikken er riktig før skriptet har kjørt.

| Tast | Gjør |
| --- | --- |
| Piltastene | Flytter mellom fanene, og går rundt fra siste til første |
| Home og End | Første og siste fane |
| Tab | Ut av raden og inn i det valgte panelet |

Bare den valgte fanen har `tabindex="0"`. Panelet har `tabindex="0"` slik at det får fokus også når det ikke har noe fokuserbart i seg, ellers hopper Tab rett forbi innholdet som nettopp ble vist.
