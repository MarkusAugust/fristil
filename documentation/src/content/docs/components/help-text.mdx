Den lille teksten under et felt som forklarer hva systemet forventer. Er teksten en feilmelding, bruk [Error Text](../error-text/).

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/help-text.css"
```

## Varianter

<Eksempel stiler={["help-text"]} layout="stabel" maxWidth="30rem" kode={`
<p class="fs-help-text">Du finner nummeret øverst til høyre på fakturaen.</p>
<p class="fs-help-text" data-variant="default">Endringen gjelder fra neste månedsskifte.</p>
<p class="fs-help-text" data-variant="success">Vedlegget er lastet opp.</p>
<p class="fs-help-text" data-variant="warning">Søknadsfristen går ut om tre dager.</p>
`} />

| `data-variant` | Brukes til |
| --- | --- |
| *(utelatt)* | Dempet. Standardvalget. |
| `default` | Full tekstfarge, når teksten må leses før feltet fylles ut |
| `success` | Bekreftelse på at noe gikk bra |
| `warning` | Noe brukeren bør vite, men som ikke stopper innsending |

## Koblet til feltet

Uten `aria-describedby` leses ikke hjelpeteksten opp når feltet får fokus.

<Eksempel stiler={["help-text", "label", "input"]} layout="stabel" maxWidth="30rem" kode={`
<label class="fs-label" for="kid">KID-nummer</label>
<input class="fs-input" id="kid" inputmode="numeric" aria-describedby="kid-hjelp" />
<p class="fs-help-text" id="kid-hjelp">Du finner nummeret øverst på fakturaen.</p>
`} />

[Field](../field/) genererer `id`-en og setter `aria-describedby` for deg.

## TypeScript

```ts
import { fs } from "@fristil/designsystem"

fs.helpText({ variant: "warning" })
// { class: "fs-help-text", "data-variant": "warning" }
```

Koblingen gjør [`fs.field`](../../typesikker-bruk/#fsfield):

```tsx
const felt = fs.field({ id: "kid", help: true })

<input {...fs.input()} {...felt.control} inputMode="numeric" />
<p {...fs.helpText()} {...felt.help}>Du finner nummeret øverst på fakturaen.</p>
```

## Tilgjengelighet

- Uten `aria-describedby` er teksten usynlig for skjermlesere. Koblingen er hele poenget.
- Hold den kort. Den leses opp rett etter ledeteksten hver gang feltet får fokus.
- Fargen skal ikke bære betydningen. En `warning` må si i ordene sine hva problemet er.
