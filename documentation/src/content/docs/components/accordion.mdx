Klassen settes på et `<details>` med et `<summary>` først. Nettleseren tar seg av åpning, lukking, tastatur og at skjermlesere melder «utvidet» eller «sammenfoldet».

Bygger du det samme av knapper og `aria-expanded`, må alt det skrives på nytt. Og teksten i et lukket panel skjules med `hidden`, så nettleserens eget søk i siden finner den ikke lenger.

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<details {...lt.accordion()}>
  <summary>Hva regnes som inntekt?</summary>
  <div className={lt.accordion.content}>Lønn, pensjon og næringsinntekt.</div>
</details>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const panel = document.querySelector<HTMLDetailsElement>("#bostotte")
if (!panel) throw new Error("fant ikke elementet")

lt.setAttributes(panel, lt.accordion({ variant: "plain" }))

panel.addEventListener("toggle", () => {
  console.log(panel.open ? "åpnet" : "lukket")
})
```

`lt.accordion.content` gir klassen på innholdet. `toggle` er nettleserens egen hendelse, og kommer både når brukeren åpner og når du setter `open` fra kode.

| Attributt | Effekt |
| --- | --- |
| `open` | Panelet står åpent når siden lastes |
| `data-variant="plain"` | Uten egen ramme, for paneler som står rett under hverandre |
| `name` på flere paneler | Bare ett kan være åpent om gangen |

`name` er nettleserens egen måte å lage et trekkspill der ett panel lukker det forrige:

```html
<details class="lt-accordion" name="sporsmal">…</details>
<details class="lt-accordion" name="sporsmal">…</details>
```

Sender serveren panelet på nytt i en oppdatering, lukkes et åpent panel: `open` er nettleserens eget attributt, og serverens utgave har det ikke. Skal det stå åpent, sender serveren `open` tilbake, i Datastar med `data-preserve-attr="open"` på panelet. Og TalkBack i Firefox på Android åpner ikke `<details>` ved aktivering; der må brukeren trykke på selve `<summary>`.

## Overskrift inni

Skal panelene være en del av sidens struktur, legg en overskrift inne i `<summary>`:

```html
<details class="lt-accordion">
  <summary><h3>Hvem kan søke om bostøtte?</h3></summary>
  <div class="lt-accordion__content">…</div>
</details>
```

Da kan skjermlesere hoppe mellom spørsmålene med overskriftsnavigasjon. Nivået må passe med resten av siden.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-accordion` | Panelet. Varianten kommer fra `data-variant`. |
| `.lt-accordion__content` | Innholdet under overskriften |

| Variabel | Standard |
| --- | --- |
| `--lt-accordion-radius` | `var(--lt-spacing-1)` |
| `--lt-accordion-padding` | `var(--lt-spacing-3) var(--lt-accordion-padding-inline)`, luften i overskriften |
| `--lt-accordion-padding-inline` | `var(--lt-spacing-4)`, luften til sidene, i overskriften og innholdet |

Pilen er tegnet med `::after` på `<summary>`, fordi nettleserens egen trekant ser ulik ut i hver nettleser. Skal du bytte den ut, holder det ikke å overstyre `content` og `border`: pseudoelementet har fast bredde og høyde og er snudd med `transform`, og vinkelen byttes når panelet er åpent og i høyre-til-venstre. Nullstill dem i samme regel. Gi et synlig tegn en tom alternativ tekst, ellers blir det en del av navnet på knappen: skjermleseren sier «Hvem kan søke? +» når `<summary>` får fokus. Overskriften beholder navnet sitt, så den som navigerer på overskrifter hører ikke tegnet. Regelen står utenfor laget og vinner derfor over alle variantene i stilarket:

```css
.lt-accordion summary::after {
	content: "+";
	inline-size: auto;
	block-size: auto;
	border: 0;
	transform: none;
}

@supports (content: "/" / "") {
	.lt-accordion summary::after {
		content: "+" / "";
	}
}
```

Skal tegnet bytte når panelet er åpent, sett det på `.lt-accordion[open] summary::after` på samme måte.

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Tilgjengelighet

- Ikke gjem noe brukeren trenger for å komme videre. Et skjemafelt som er påkrevd hører ikke hjemme i et lukket panel.
- Overskriften i `<summary>` skal si hva som kommer, ikke «Les mer».
- La panelet som inneholder en feil åpne seg når skjemaet valideres. Ellers ser brukeren en feilmelding uten å finne feltet.
- `<summary>` er allerede en knapp for nettleseren. Ikke legg en knapp inni den.
