Et lite merke som viser hvilken tilstand noe er i. Fargen styres med `data-color`.

## Slik tar du den i bruk

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<span {...lt.badge()}>Under behandling</span>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Har du elementet som en variabel,** setter du dem på det med `setAttributes`. Det er veien uten JSX, enten du nettopp lagde elementet eller fant det i en side serveren sendte:

```ts
import { lt, type BadgeColor } from "@lo-tek/interfaces"

const merke = document.createElement("span")
merke.textContent = "Innvilget"

lt.setAttributes(merke, lt.badge({ color: "success" }))
```

Kommer fargen fra et API, valider den først:

```ts
const farge: BadgeColor = lt.badge.isColor(svar.status) ? svar.status : "info"

lt.setAttributes(merke, lt.badge({ color: farge }))
```

`lt.setAttributes` rydder også bort attributter fra forrige kall, så merket kan skifte farge uten at den gamle blir stående. Se [Typesikker bruk](../../type-safe-use/).

| `data-color` | Brukes til |
| --- | --- |
| *(utelatt)* | Informasjon, pågående tilstand. `lt.badge({ color: "info" })` gir det samme, uten attributt |
| `success` | Fullført, godkjent, aktiv |
| `warning` | Krever oppmerksomhet, men er ikke en feil |
| `danger` | Avslått, utløpt, kritisk |
| `neutral` | Inaktiv, arkivert, ukjent |

## I en liste

Merket står som regel sammen med det det sier noe om. Her i en [List](../list/) med skille mellom radene:

<Example stiler={["badge", "list"]} layout="stabel" maxWidth="26rem" kode={`
<ul class="lt-list" data-variant="divided">
  <li>Faktura 2026-0481 <span class="lt-badge" data-color="success">Betalt</span></li>
  <li>Faktura 2026-0482 <span class="lt-badge" data-color="danger">Forfalt</span></li>
</ul>
`} />

Skal merket stå til høyre i raden, er det appens oppsett som avgjør det, med `display: flex` og `justify-content: space-between` på `li`-elementet.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-badge` | Selve merket. Fargen kommer fra `data-color`. |

| Variabel | Standard |
| --- | --- |
| `--lt-badge-padding` | `var(--lt-spacing-0-5) var(--lt-spacing-2)` |
| `--lt-badge-radius` | `var(--lt-spacing-4)` |

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Tilgjengelighet

- Fargen alene sier ingenting til en skjermleser. Teksten må bære betydningen: «Avslått», ikke bare et rødt punkt.
- `<span>` inni en tekstlinje, `<div>` når merket står alene.
- Endrer merket seg mens siden står stille, legg `role="status"` og `aria-live="polite"` på elementet rundt.
