Den lille teksten under et felt som forklarer hva systemet forventer. Er teksten en feilmelding, bruk [Error Text](../error-text/).

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<p {...lt.helpText()}>Du finner nummeret øverst til høyre på fakturaen.</p>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const ledetekst = document.querySelector<HTMLLabelElement>("#kid-label")
const input = document.querySelector<HTMLInputElement>("#kid")
const hjelpetekst = document.querySelector<HTMLElement>("#kid-help")

const felt = lt.field({ id: "kid", help: true })

lt.setAttributes(ledetekst, felt.label)
lt.setAttributes(input, lt.input(), felt.control)
lt.setAttributes(hjelpetekst, lt.helpText(), felt.help)
```

[`lt.field`](../field/) genererer `id`-en og setter `aria-describedby`, så koblingen ikke kan glemmes.

Trenger du bare klassen:

```ts
lt.setAttributes(hjelpetekst, lt.helpText({ variant: "warning" }))
```

| `data-variant` | Brukes til |
| --- | --- |
| *(utelatt)* | Dempet. Standardvalget. |
| `strong` | Full tekstfarge, når teksten må leses før feltet fylles ut |
| `success` | Bekreftelse på at noe gikk bra |
| `warning` | Noe brukeren bør vite, men som ikke stopper innsending |

## Koblet til feltet

Uten `aria-describedby` leses ikke hjelpeteksten opp når feltet får fokus.

<Example stiler={["help-text", "label", "input"]} layout="stabel" maxWidth="30rem" kode={`
<label class="lt-label" for="kid">KID-nummer</label>
<input class="lt-input" id="kid" inputmode="numeric" aria-describedby="kid-hjelp" />
<p class="lt-help-text" id="kid-hjelp">Du finner nummeret øverst på fakturaen.</p>
`} />

[Field](../field/) genererer `id`-en og setter `aria-describedby` for deg.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-help-text` | Teksten. Fargen kommer fra `data-variant`. |

Se [Tilpasning](../../customising/) for hvordan laget virker.

## Accessibility

- Uten `aria-describedby` er teksten usynlig for skjermlesere. Koblingen er hele poenget.
- Hold den kort. Den leses opp rett etter ledeteksten hver gang feltet får fokus.
- Fargen skal ikke bære betydningen. En `warning` må si i ordene sine hva problemet er.
