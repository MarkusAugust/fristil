Brødtekst med lesbar linjelengde. Bredden er begrenset til 70 tegn, fordi lengre linjer gjør det vanskelig å finne tilbake til starten av neste. Det er den vanligste grunnen til at en tekst er tung å lese selv når skriften er stor nok.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<p {...lt.paragraph({ variant: "lead" })}>
  Bostøtte er en behovsprøvd støtte til deg som har lave inntekter.
</p>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const ingress = document.querySelector<HTMLParagraphElement>("#ingress")

lt.setAttributes(ingress, lt.paragraph({ variant: "lead" }))
```

| Attributt | Brukes til |
| --- | --- |
| *(utelatt)* | Brødtekst |
| `data-variant="lead"` | Ingressen rett under overskriften |
| `data-size="large"` | Tekst som skal løftes fram |
| `data-size="small"` | Bisetninger, datoer, kildehenvisninger |

Avsnitt som følger hverandre får luft mellom seg av seg selv.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-paragraph` | Avsnittet. Størrelsen kommer fra `data-size`, ingressen fra `data-variant`. |

| Variabel | Standard |
| --- | --- |
| `--lt-paragraph-width` | `70ch` |
| `--lt-paragraph-gap` | `var(--lt-spacing-3)` |
| `--lt-paragraph-line-height` | `var(--lt-line-height-article)` |

`--lt-paragraph-line-height` gjelder standardstørrelsen. `data-size="large"` og `data-variant="lead"` setter sin egen linjehøyde.

Står avsnittet i en spalte som allerede er smal nok, kan grensen fjernes:

```css
.lt-card .lt-paragraph {
	--lt-paragraph-width: none;
}
```

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Accessibility

- Ikke bruk `<br>` for å lage avsnitt. Et nytt `<p>` er det skjermlesere kan hoppe mellom.
- `data-size="small"` skal ikke brukes på noe brukeren må lese. Vilkår i liten skrift er like vanskelige på skjerm som på papir.
- La linjelengden stå. Den er den enkleste forskjellen mellom en tekst som leses og en som skummes.
