Lenkestil med tydelig understrek, hover og fokusmarkering. Skal lenken se ut som en knapp, bruk [Button](../button/) på `<a>`-elementet i stedet.

`fs` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { fs } from "@fristil/designsystem/react"

<a {...fs.link()} href="/kvittering">Se kvittering</a>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@fristil/designsystem` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { fs } from "@fristil/designsystem"

const lenke = document.querySelector<HTMLAnchorElement>("#arsoppgave")

fs.setAttributes(lenke, fs.link({ disabled: !klar }))
if (klar) lenke?.setAttribute("href", "/arsoppgave")
else lenke?.removeAttribute("href")
```

`href` er appens, ikke byggefunksjonens, så den setter og fjerner du selv. Blir årsoppgaven klar senere, kjører du begge linjene på nytt. Da fjernes `aria-disabled`, `role` og `tabindex`, og lenken virker igjen. `fs.link()` forvalter alle tre, så en `role` eller `tabindex` du har satt selv på samme lenke, fjernes også. Trenger lenken dem, sett dem etter `setAttributes`.

## Deaktivert lenke

<Eksempel stiler={["link"]} kode={`
<a class="fs-link" href="#">Se kvittering</a>
<a class="fs-link" role="link" tabindex="0" aria-disabled="true">Se årsoppgave</a>
`} />

En deaktivert lenke har ingen `href`. `aria-disabled="true"` demper fargen og slår av musa med `pointer-events: none`, men tastaturet følger `href` med Enter uansett. Derfor må den bort.

Uten `href` er en `<a>` ingen lenke for skjermleseren, og den står ikke i tabrekkefølgen. `role="link"` og `tabindex="0"` gir den begge tilbake, så skjermlesere finner den og kan si at den er utilgjengelig. `fs.link({ disabled: true })` gir alle tre.

`fristil sjekk` melder en `fs-link` eller `fs-button` med både `aria-disabled="true"` og `href` (regelen `deaktivert-med-href`).

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.fs-link` | Lenken. Besøkt og deaktivert skiller seg med `:visited` og `aria-disabled`. |

Se [Tilpasning](../../tilpasning/) for hvordan laget virker.

## Tilgjengelighet

- Lenketeksten skal gi mening lest alene. Skjermlesere kan liste opp alle lenker på siden, og der hjelper «Se faktura for mars» der «Klikk her» ikke sier noe.
- Ikke fjern `outline` på `:focus-visible`. Den er det eneste tastaturbrukere navigerer etter.
- Åpner lenken i ny fane, si det i teksten eller med `aria-label`.
