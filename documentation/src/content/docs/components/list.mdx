Klassen settes på `<ul>` eller `<ol>` og gir listen riktig luft og innrykk. Variantene fjerner punktene visuelt uten å fjerne selve listen. Unntaket er Safari, der VoiceOver kan la være å lese en `<ul>` uten synlige punkter som en liste. En `<ol>` og en liste i `<nav>` beholder den. Er antallet viktig for den som hører siden, sett `role="list"` på `<ul>`.

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<ul {...lt.list({ variant: "divided" })}>
  <li>Søknad om bostøtte</li>
  <li>Søknad om startlån</li>
</ul>
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const liste = document.querySelector<HTMLUListElement>("#vedlegg")

lt.setAttributes(liste, lt.list({ variant: "divided" }))
```

| `data-variant` | Brukes til |
| --- | --- |
| *(utelatt)* | Punkter eller tall, med innrykk |
| `plain` | Uten punkter, for lister som bærer sin egen struktur |
| `divided` | Uten punkter, med strek mellom radene |

## Hvorfor varianten finnes

Uten `plain` ville folk skrevet `<div>` for å bli kvitt punktene, og da forsvinner opplysningen om at dette er en liste med fire elementer. Varianten fjerner utseendet, ikke betydningen, med unntaket for Safari over.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-list` | Listen. Varianten kommer fra `data-variant`. |

| Variabel | Standard |
| --- | --- |
| `--lt-list-gap` | `var(--lt-spacing-1)`, og `var(--lt-spacing-2)` i `divided` |

`--lt-list-gap` er avstanden mellom elementene, og blir til luft over og under hver rad i `divided`. De to har ulik standardverdi, så setter du variabelen gjelder tallet ditt begge steder. Se [Tilpasning](../../customising/).

## Accessibility

- Bruk `<ol>` når rekkefølgen betyr noe, som i en oppskrift eller en saksgang. Bruk `<ul>` ellers.
- Ikke legg annet enn `<li>` rett inni listen. Et `<div>` mellom bryter koblingen mellom listen og elementene.
- Lister av lenker bør ligge i en liste også når de ser ut som en meny. Da sier skjermleseren hvor mange valg det er.
