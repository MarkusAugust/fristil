`ds-textarea` er en pure-css stil for `<textarea>` med samme state-mønster som input.

## Import

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/textarea.css"
```

## TypeScript-API

```ts
import {
  getTextareaStyleAttributes,
  type TextareaState,
} from "@fristil/designsystem/textarea"

const state: TextareaState = "success"
const fristilAttributes = getTextareaStyleAttributes(state)

// fristilAttributes blir:
// { class: "ds-textarea", "data-state": "success" }
```

## Runtime input (for eksempel fra API)

```ts
import { isTextareaState, getTextareaStyleAttributes } from "@fristil/designsystem/textarea"

const incoming = String(payload.state)
const state = isTextareaState(incoming) ? incoming : "default"
const fristilAttributes = getTextareaStyleAttributes(state)
```
