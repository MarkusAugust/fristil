import { Tabs, TabItem } from "@astrojs/starlight/designsystem"

`ds-button` er en **pure-css**-komponent: ren CSS-klasse, null JavaScript, fungerer i alle rammeverk.

## Import

```html
<link rel="stylesheet" href="@fristil/designsystem/tokens.css" />
<link rel="stylesheet" href="@fristil/designsystem/button.css" />
```

Via bundler:

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/button.css"
```

| Variant | Bruk |
|---------|------|
| *(ingen)* | Primær handling — én per side |
| `secondary` | Sekundær handling ved siden av primær |
| `ghost` | Lav vekt — verktøylinjer, inline-handlinger |
| `danger` | Destruktive handlinger — slett, avbryt |

For ikke-`<button>`-elementer (f.eks. `<a>`), bruk `aria-disabled="true"` i stedet for `disabled`:

```html
<a class="ds-button" aria-disabled="true" href="/handling">Primær</a>
```

## Tilgjengelighet

- Bruk alltid `<button>` for handlinger og `<a>` for navigasjon
- `<button>` har `type="button"` som standard i skjemaer — sett `type="submit"` eksplisitt ved behov
- Teksten i knappen skal beskrive handlingen, ikke resultatet: *«Slett bruker»*, ikke *«OK»*
- Unngå å deaktivere knapper som eneste feilhåndtering — vis heller en feilmelding
