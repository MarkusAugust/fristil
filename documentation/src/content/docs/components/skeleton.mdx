Grå former som viser hvor innholdet kommer. De er alltid skjult for skjermlesere, så ventingen må meldes ett sted i tillegg. Er det ingen form å vise, eller tar ventingen kort tid, er [Spinner](../spinner/) enklere.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<div {...lt.skeleton({ variant: "circle" })} />
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Har du elementet som en variabel,** setter du dem på det med `setAttributes`. Det er veien uten JSX, enten du nettopp lagde elementet eller fant det i en side serveren sendte:

```ts
import { lt } from "@lo-tek/interfaces"

const linje = document.createElement("div")

lt.setAttributes(linje, lt.skeleton({ variant: "text" }))
```

| `data-variant` | Brukes til |
| --- | --- |
| *(utelatt)* | Blokk, for bilder og kort |
| `text` | Én tekstlinje |
| `circle` | Profilbilde |

Blokken og tekstlinjene fyller bredden de får, mens `circle` er like bred som den er høy. `sak-siste-linje` og `sak-bilde` er dine egne klasser, ikke LO-TEKs, og de står i «Plain HTML»-fanen over sammen med markupen.

Sett bredden på den siste linjen til under 100 prosent. Et avsnitt der alle linjene er like lange ser ikke ut som tekst.

## Ventingen må meldes ett sted

```html
<div id="innhold" aria-busy="true">
  <p class="lt-sr-only" role="status">Henter søknadene dine</p>
  <div class="lt-skeleton" data-variant="text" aria-hidden="true"></div>
  <div class="lt-skeleton" data-variant="text" aria-hidden="true"></div>
</div>
```

En rekke tomme bokser som leses opp er verre enn stillhet. Derfor setter `lt.skeleton()` alltid `aria-hidden="true"`, og beskjeden legges i et eget felt med `role="status"`.

Når innholdet kommer, fjern `aria-busy` og tøm statusfeltet.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-skeleton` | Plassholderen. Formen kommer fra `data-variant`. |

| Variabel | Standard |
| --- | --- |
| `--lt-skeleton-height` | `var(--lt-spacing-4)`, og `var(--lt-spacing-10)` i `circle`, der den også gir bredden. `text` leser den ikke: der kommer høyden fra `--lt-font-size-m` |
| `--lt-skeleton-radius` | `var(--lt-spacing-1)`, og `var(--lt-spacing-0-5)` i `text` |

Skimmeret er en gradient som beveger seg over flaten, ikke en gjennomsiktighet som pulserer, så kontrasten mot sideflaten er den samme hele veien. Har brukeren bedt om mindre bevegelse, står flaten stille.

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Accessibility

- Formene skal ligne på det som kommer. En plassholder som er tre linjer der resultatet er tjue, gjør siden urolig når innholdet lander.
- Vent litt før du viser dem, som med en venteindikator. Et glimt av grå bokser er mer forstyrrende enn en kort pause.
- Ikke la dem bli stående hvis noe feiler. Da venter brukeren på noe som aldri kommer. Bytt til en [Alert](../alert/) med hva som gikk galt.
