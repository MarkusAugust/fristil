The components fall into three groups, split by who creates the markup and whether a web component adds behaviour to it. That decides what you write yourself and what the system does for you. The reasoning is in [Markup and behaviour](../markup-and-behaviour/).

Every page shows the component in plain HTML and with the builder function in TypeScript, with code you can paste straight in. The web components also have tabs for React and Datastar, and most have one for Astro.
