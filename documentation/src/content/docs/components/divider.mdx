Klassen settes på et vanlig `<hr>`. Nettleserens egen strek har både ramme og høyde, og begge må nullstilles før fargen fra tokenene er den eneste som vises. Den har også auto-marger til sidene, som i en flex-kolonne gjør streken 0 piksler bred. Klassen nullstiller dem, så streken fyller bredden.

## How to use it

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<hr {...lt.divider({ variant: "subtle" })} />
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Har du elementet som en variabel,** setter du dem på det med `setAttributes`. Det er veien uten JSX, enten du nettopp lagde elementet eller fant det i en side serveren sendte:

```ts
import { lt } from "@lo-tek/interfaces"

const strek = document.createElement("hr")

lt.setAttributes(strek, lt.divider({ variant: "subtle" }))
```

| `data-variant` | Brukes til |
| --- | --- |
| *(utelatt)* | Vanlig skille mellom to deler |
| `strong` | Tydelig skille, for eksempel før en oppsummering |
| `subtle` | Svakt skille mellom rader i en liste |

## Når streken ikke skal leses opp

`<hr>` melder seg som et skille i innholdet. Er streken bare pynt mellom to bokser som allerede er atskilt visuelt, si fra at den ikke betyr noe:

```html
<hr class="lt-divider" data-variant="subtle" aria-hidden="true" />
```

Skiller den derimot to virkelige deler av siden, skal den bli stående i tilgjengelighetstreet. Den er da den eneste måten skjermleseren får vite at et emne er slutt.

## Classes you can style

| Klasse | Hva det er |
| --- | --- |
| `.lt-divider` | Streken. Styrken kommer fra `data-variant`. |

| Variabel | Standard |
| --- | --- |
| `--lt-divider-space` | `var(--lt-spacing-4)` |

`--lt-divider-space` er luften over og under streken. Se [Tilpasning](../../customising/).

## Accessibility

- Ikke bruk en strek der en overskrift hører hjemme. En overskrift sier hva som kommer; en strek sier bare at noe er slutt.
- En strek mellom hvert element i en liste er støy for den som hører siden. Bruk heller `aria-hidden="true"`, eller la være.
