Klassen settes på et vanlig `<input type="file">`. Knappen inni er nettleserens egen, og teksten på den kommer fra operativsystemets språk. Den kan ikke oversettes, så ledeteksten over feltet må si hva som skal lastes opp.

`lt` brukes på to måter, og hvilken avhenger av om du lager elementet eller finner det.

**Lager du markupen,** sprer du attributtene inn. Det er veien i React, Astro og alt annet som rendrer:

```tsx
import { lt } from "@lo-tek/interfaces/react"

<input {...lt.fileUpload()} id="vedlegg" accept=".pdf,.jpg" />
```

Importen går til `/react` her, siden blokka er JSX. Derfra heter nøklene `className` og `htmlFor`. I Astro og alt annet uten React importerer du `@lo-tek/interfaces` og får `class` og `for`.

**Står elementet der fra før,** setter du dem på det. Det er veien når du forbedrer HTML en server eller en mal har sendt:

```ts
import { lt } from "@lo-tek/interfaces"

const felt = document.querySelector<HTMLInputElement>("#vedlegg")

lt.setAttributes(felt, lt.fileUpload({ multiple: true, accept: ".pdf" }))
```

`lt.fileUpload.list` gir klassen på lista. Se [Typesikker bruk](../../type-safe-use/).

| Attributt | Effekt |
| --- | --- |
| `multiple` | Flere filer kan velges |
| `accept` | Filtypene filvelgeren foreslår |
| `data-state="invalid"` | Rød ramme. Sett `aria-invalid="true"` i tillegg. |
| `data-state="success"` | Grønn ramme |

`accept` er en hjelp i filvelgeren, ikke en sperre. Brukeren kan velge «alle filer», så typen må sjekkes på serveren uansett.

## Lista over valgte filer

Lista skriver du selv, siden bare du vet hva som skal skje når en fil fjernes.

Knappeteksten skal si hvilken fil som fjernes. «Fjern» alene gir like knapper for den som hører siden.

Feltet husker bare det siste utvalget: velger brukeren to filer til, erstatter de forrige. Skal filene samles opp, og kunne fjernes én og én, må du holde lista selv, og sende den selv:

```html
<form action="/soknad/vedlegg">
  <label class="lt-label" for="vedlegg">Last opp vedlegg</label>
  <input class="lt-file-upload" type="file" id="vedlegg" name="vedlegg" multiple />
  <ul class="lt-file-upload-list"></ul>
  <button class="lt-button" type="submit">Send</button>
</form>
```

```js
const felt = document.getElementById("vedlegg")
const skjema = felt.form
let filer = []

felt.addEventListener("change", () => {
  filer = [...filer, ...felt.files]
  // Tegn lista over filene her, med en «Fjern»-knapp per fil.
  felt.value = ""
})

skjema.addEventListener("submit", async (hendelse) => {
  hendelse.preventDefault()
  const data = new FormData(skjema)
  // Det tomme feltet ville ellers sendt en tom fil under sitt eget navn.
  data.delete(felt.name)
  for (const fil of filer) data.append(felt.name, fil)
  await fetch(skjema.action, { method: "POST", body: data })
})
```

Feltet må stå i et `<form>` og ha et `name`. Det er tømt etter hvert valg, så en vanlig innsending tar ikke med noen av filene. Derfor sendes skjemaet med `fetch`, med filene lagt til i `FormData`.

## Klasser du kan style

| Klasse | Hva det er |
| --- | --- |
| `.lt-file-upload` | Feltet. Tilstanden kommer fra `data-state`. |
| `.lt-file-upload-list` | Lista over filene som er valgt |

| Variabel | Standard |
| --- | --- |
| `--lt-file-upload-padding` | `var(--lt-spacing-2)` |
| `--lt-file-upload-radius` | `var(--lt-spacing-1)` |

Knappen inne i feltet styles gjennom `::file-selector-button`, som er den eneste veien inn til den.

Se [Tilpasning](../../customising/) for hvordan variablene og laget virker.

## Tilgjengelighet

- Si hvilke filtyper og hvilken største størrelse som godtas, før brukeren prøver. En feilmelding etterpå er et dårligere alternativ.
- Meld fra når en fil er lagt til eller fjernet, i et felt med `role="status"`.
- Dra-og-slipp kan komme i tillegg, aldri i stedet. Det finnes ikke for tastatur.
- Under opplasting: vis fremdrift per fil, og la brukeren avbryte.
