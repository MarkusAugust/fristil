`fs-badge` er et lite merke du setter ved siden av noe annet for å vise hvilken tilstand det er i — en søknad som er innvilget, en faktura som har forfalt. Fargen styres med `data-color`.

## Importer

```js
import "@fristil/designsystem/tokens.css"
import "@fristil/designsystem/badge.css"
```

Uten byggesteg:

```html
<link rel="stylesheet" href="@fristil/designsystem/tokens.css" />
<link rel="stylesheet" href="@fristil/designsystem/badge.css" />
```

| `data-color` | Tokens | Når du bruker den |
| --- | --- | --- |
| *(utelatt)* | `interactive-background` / `interactive-main` | Nøytral informasjon, pågående tilstand |
| `success` | `success-background` / `success-foreground` | Fullført, godkjent, aktiv |
| `warning` | `warning-background` / `warning-foreground` | Krever oppmerksomhet, men er ikke en feil |
| `danger` | `danger-background` / `danger-foreground` | Avslått, utløpt, kritisk |
| `neutral` | `neutral-background` / `neutral-foreground` | Inaktiv, arkivert, ukjent |

## Tilgjengelighet

- Fargen alene forteller ingenting til en skjermleser, og skiller ikke for alle seende heller. Teksten i merket må stå på egne bein: skriv «Avslått», ikke bare et rødt punkt.
- Alle fem fargeparene er kontrollert mot WCAG AA, og en test i `badge.browser.test.ts` sier fra hvis en tokenendring bryter det.
- Bruk `<span>` når merket står inni en tekstlinje, `<div>` når det står for seg selv.
- Endrer merket seg mens brukeren ser på siden — for eksempel fra «Under behandling» til «Innvilget» — legg `role="status"` og `aria-live="polite"` på elementet rundt, så blir endringen lest opp.
